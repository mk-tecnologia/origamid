## 📖 Sobre
**Origamid** é um curso de UX/UI design HTML, CSS, Javascript e outras tecnologia com enfase no Front-End.

```Site Curso```: [ORIGAMID](https://origamid.com)

* **HTML/CSS**
* **UI Design para Iniciantes**
* **CSS Flexbox**
* **CSS Grid Layout**
* **UI Design Avançado**
* **JavaScript Completo ES6**
* **WordPress REST API Dogs**
* **Tailwind CSS**
* **TypeScript para Iniciantes**
* **React com TypeScript**
* **Next.js**
* **Redux com React**
* **WordPress Como CMS**
* **CSS Avançado Posicionamento**
* **UX Design Heurísticas**
* **WordPress REST API**

* **Bootstrap 4**
* **Automação Front End com NPM**
* **JavaScript e jQuery**
* **Adobe XD**
* **Vue.js 2 Completo**
